Architecture & Verification Flow

This implementation executes a complete Real World Asset (RWA) claim backed loan lifecycle directly on Nervos CKB Testnet (Pudge) with no bridges or off-chain price oracles.

1. Native RWA Asset

Single Cell representing a verified claim (e.g., warehouse commodity receipt or commercial trade invoice). Governed by the rwa-asset-type RISC-V contract.

2. Mocked KYC Attestation

Issuer-revocable attestation Cell storing the subject lock hash and pass status. Proves eligibility without requiring external oracle dependencies at execution.

3. Loan Cell State Machine

Carries 33 bytes: borrower lock hash + state (0x00 deposited, 0x01 borrowed, 0x02 repaid). Script args fix loan amount, repay amount, and unix deadline.

4. Release & Repay Settlement

Repay transaction transfers pre-agreed loan + interest tokens back to lender. Release consumes loan cell and returns original RWA asset cell to borrower.
